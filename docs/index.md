# Repuragent - AI Scientist for Drug Repurposing

Repuragent is an Agentic AI system for Drug Repurposing delivered in two versions—a self-hosted local build and a public web-app build. This guide treats both versions as one product line so you can understand what stays the same, what differs, and how to choose the right experience for your team.

- [GitHub for local app](https://github.com/pharmbio/repuragent)
- [Web-app version](https://repuragent.serve.scilifelab.se)

## How to Use This Guide
- Start with the overview to learn what are the Repuragent's general features and how the versions compare.
- Follow the version-specific guide (local or web) that matches your usage target.
- Consult the operations and troubleshooting chapters when you need to customize, scale, or debug Repuragent.
